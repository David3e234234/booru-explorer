# Booru Explorer

Booru Explorer — это полнофункциональный веб-клиент для поиска, просмотра и каталогизации медиа-контента с популярных Booru-борд и архивов подписок. Поддерживает видео со звуком, многостраничные альбомы, распаковку архивов, умные рекомендации, авторизацию и проксирование.

---

## Ключевые возможности

- **Поддерживаемые источники**:
  - **Booru-борды**: Danbooru, Gelbooru, Rule34, Yande.re, Konachan, Safebooru, Rule34Video, Xbooru, Hypnohub, TBIB.
  - **Архивы подписок**: Kemono (`kemono.cr`), Pawchive (`pawchive.pw`) — поддержка Patreon, Pixiv Fanbox, Fantia, Boosty, Gumroad, Discord, SubscribeStar и др.
  - **Мульти-поиск**: одновременный поиск по всем или выбранным источникам с объединением выдачи.
  - **Фильтрация по платформе**: быстрый выбор сервиса (Patreon, Fanbox, Fantia и т.д.) для Kemono и Pawchive.

- **Многостраничные посты и архивы**:
  - Объединение многофайловых постов в альбомы с быстрым переключением страниц в просмотрщике.
  - Встроенный инспектор архивов (`.zip`, `.rar`, `.7z`): предпросмотр файлов, извлечение медиа в просмотрщик и скачивание отдельных файлов без загрузки всего архива целиком.

- **Видеоплеер и медиа**:
  - Предпросмотр видео при наведении курсора и автовоспроизведение в ленте.
  - Полноэкранный плеер с поддержкой звука, выбором качества и кэшированием.
  - Серверный транскодер FFmpeg для форматов, не поддерживаемых браузером напрямую.

- **Авторизация и синхронизация аккаунтов**:
  - Поддержка API-ключей и токенов сессий (Danbooru, Gelbooru, Rule34, Yande.re, Konachan, Pawchive, Kemono).
  - Выгрузка и синхронизация лайков, избранного и подписок на авторов в сторонние аккаунты.

- **Авторы, подписки и рекомендации**:
  - Автоматическое распознавание художников и профилей (Twitter/X, Pixiv, Fanbox, Patreon, ArtStation).
  - Вкладка «Отслеживаемое» — персональная лента обновлений отслеживаемых авторов.
  - Умная система рекомендаций на основе интересов и лайков пользователя.
  - Выбор обложек авторов из их работ.

- **Сетевые настройки и прокси**:
  - Настройка глобального или индивидуального HTTP/HTTPS/SOCKS5 прокси для каждого источника.
  - Встроенный кэш медиафайлов и превью на сервере с контролем лимита диска.
  - Автоматическое резервное копирование данных в Telegram-бота.

- **Фильтрация и поиск**:
  - Фильтр ИИ-контента: все, без ИИ, только ИИ.
  - Фильтры типов (изображения, видео, анимации, архивы), рейтингов (SFW / Questionable / NSFW) и телосложения.
  - Умный автокомплит тегов и черный список исключений.

- **Интерфейс и адаптивность**:
  - Мобильная версия с поддержкой PWA и тач-жестов.
  - Локализация интерфейса (русский / английский).
  - Поддержка тем оформления (Kotobox, Warm Paper, Dark).
  - Скрипт `start_phone.bat` для быстрого подключения смартфона по локальной сети через QR-код.

## Установка и запуск

### Требования
* Node.js (версия 18 или новее)
* FFmpeg (опционально, рекомендуется для создания превью видео и транскодирования)

### Запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/David3e234234/booru-explorer.git
cd booru-explorer
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект:
* **На Windows**: запустите `start.bat` (или `start_phone.bat` для доступа с телефона по QR-коду)
* **Через терминал**:
```bash
npm start
```
* **Без автоматического открытия браузера**:
```bash
node server.js --no-open
```

Приложение будет доступно по адресу: `http://localhost:3000` (порт автоматически переключается, если 3000 занят, либо задается через `--port=N`).

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `←` / `→` | Предыдущий / следующий пост |
| `↑` / `↓` | Предыдущая / следующая страница в альбоме |
| `F` | Добавить / убрать из Избранного |
| `L` | Поставить лайк посту |
| `Esc` | Закрыть просмотрщик |
| Колесико мыши | Приближение (Zoom) |
| Двойной клик | Сброс зума / 2x приближение |

---

## Хранение данных

Все пользовательские настройки, избранное, авторы, кэш и данные сессий хранятся локально в директории `data/`. Шаблон конфигурации доступен в `data/settings.example.json`.
