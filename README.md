# Booru Explorer

Booru Explorer — это клиент для просмотра и поиска медиа-контента с различных Booru-платформ. Поддерживает видео, аудио, извлечение метаданных и фильтрацию контента.

---

## Ключевые возможности

- **Поддерживаемые источники**: 
  - Danbooru, Gelbooru, Rule34, Yande.re, Konachan, Safebooru, Rule34Video, Xbooru, Hypnohub.
  - Режим агрегации (поиск по всем сайтам одновременно).
- **Видеоплеер**:
  - Предпросмотр видео при наведении.
  - Встроенный плеер с поддержкой звука и кэширования.
  - FFmpeg транскодер для неподдерживаемых браузером форматов.
- **Метаданные**:
  - Распознавание профилей художников (Twitter/X, Pixiv, ArtStation и др.).
  - Поиск по автору в один клик.
  - Отображение исходного качества и рейтинга.
- **Фильтрация ИИ-контента**:
  - Режимы отображения: все, без ИИ, только ИИ.
- **Работа с тегами**:
  - Автокомплит с разбивкой по категориям.
  - Исключение нежелательных тегов через черный список.
- **Просмотрщик**:
  - Pan & Zoom для изображений.
  - Скачивание файлов.
  - Локальное избранное.
- **Мобильная версия**:
  - Адаптивный интерфейс (PWA).
  - Скрипт `start_phone.bat` для генерации QR-кода и подключения в локальной сети.

## Установка и запуск

### Требования
* Node.js (версия 18 или новее)

### Запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/David3e234234/booru-explorer.git
cd booru-explorer
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект:
* **На Windows**: запустите `start.bat` (или `start_phone.bat` для мобильного доступа)
* **Через терминал**:
```bash
npm start
```

Приложение будет доступно по адресу: `http://localhost:3000`

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `←` / `→` | Предыдущий / следующий пост |
| `F` | Добавить / убрать из Избранного |
| `Esc` | Закрыть просмотрщик |
| Колесико мыши | Приближение (Zoom) |
| Двойной клик | Сброс зума / 2x приближение |

## Хранение данных

Пользовательские настройки, избранное и API-ключи хранятся локально в папке `data/`. Шаблон конфигурации доступен в `data/settings.example.json`.
