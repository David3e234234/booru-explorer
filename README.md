## ⚡ Быстрый старт

### Требования
* [Node.js](https://nodejs.org/) (версия 18 или новее)

### Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/booru-explorer.git
cd booru-explorer
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект:
* **На Windows**: просто дважды кликните по **`start.bat`** (или **`start_phone.bat`** для доступа с телефона)
* **Через терминал**:
```bash
npm start
```

Приложение откроется в браузере по адресу: **`http://localhost:3000`**
